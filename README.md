# Personal Expense Tracker

A beginner-friendly Python command-line application for recording and reviewing personal expenses.

## Features
- Add expenses with category and date
- View saved expenses
- Calculate total spending
- Show category-wise spending
- Store data locally in CSV format

## Concepts Used
Python, functions, lists, dictionaries, CSV file handling, loops, conditionals, and basic data processing.

## Requirements
Python 3.x. No external packages are required.

## Run
```bash
python expense_tracker.py
```

## Learning Goal
The project demonstrates practical Python file handling and basic data analysis through a simple command-line application.
